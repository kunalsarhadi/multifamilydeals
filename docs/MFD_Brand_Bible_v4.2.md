## 4. Forbidden & Encouraged Language
**Forbidden in premium/client work + website:**
- Hype ("ANOTHER WIN!", "NOW SELLING!"), excess exclamation/emoji, clichés ("dream home", "perfect opportunity"), vague claims without numbers.
- AI filler ("ensuring", "leverage", "seamless", "robust", "navigate", "comprehensive"). "I hope this finds you well." "Best regards/Sincerely" (use "Kunal" / "Regards, Kunal").
- **"Guaranteed" / "risk-free" / "locked in."**
- **"You qualify" / "you'll save $X" / "you'll cashflow $X"** — only CMHC and the lender qualify; never quote specific savings as a promise. Use **"projected."**
- **"We get you approved."**
- **"$0 mortgage broker fees"** — we offer a **preferred broker partner** (broker is compensated by the lender), not zero fees.
- **"Pari Passu"** — use **"refinancing or a HELOC."** (v4.2)
- **Letter of Intent described/portrayed as "confirming/guaranteeing the financing structure"** — an LOI is a pre-approval. Name it; don't explain or over-claim it. (v4.2)
- **"Written into the constitution"** re: Alberta taxes — it's long-standing **policy**, not constitutional. (v4.2)
- **"Our properties are GST-exempt"** — qualify: **"may qualify, subject to CRA eligibility."**
- **"Premier / best / top / #1"** without a verifiable named source (incl. soften **"#1 interprovincial migration"** → "among Canada's strongest").
- **"25-year conventional amortization"** — conventional is **30-year** (with 20%+ down). See §18.
- **"MLI Select doesn't qualify in Ontario/BC" / "the math is closed"** — technically wrong. See §18.
- **"Strategy call"** — use **"discovery call."**
- Em dashes in conversational outputs (SMS/WhatsApp/AI) — read as AI-generated.

**Encouraged everywhere:** specific $ and %, side-by-side Ontario-vs-Alberta math, owner-posture language (operator, portfolio, foundation, structure), DSCR/MLI Select/50-year amortization used confidently, **"as low as 5% down"** (not flat "5% down").
